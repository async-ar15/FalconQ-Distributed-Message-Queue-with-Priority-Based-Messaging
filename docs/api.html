API Reference

Publishing Messages

POST /topic/{topic_name}/publish

Appends a new message to the specified topic. The message will be routed to a partition based on the cluster's consistent hashing ring.

message
string (required)
The raw string or JSON payload to store in the queue.
priority
string (optional)
Set to "high" to route to the High-Priority Queue. Default is "low".
curl -X POST http://localhost:8080/topic/orders/publish \
  -H "Content-Type: application/json" \
  -d '{"message": "Urgent refund request", "priority": "high"}'

Consuming Messages

GET /topic/{topic_name}/consume

Consumes a batch of messages from the topic. High-priority messages are always drained before low-priority ones. This endpoint is stateful: it automatically tracks and increments the read offset for the provided consumerID.

consumerID
string (required)
A unique identifier for the consumer (or consumer group).
batch
integer (optional)
Number of messages to pull in a single request. Default is 10.
curl "http://localhost:8080/topic/orders/consume?consumerID=worker-node-1&batch=5"

Peeking Messages

GET /topic/{topic_name}/peek

Statelessly retrieves messages starting from a specific absolute offset without updating any consumer state.

offset
integer (required)
The exact commit log offset to start reading from.
batch
integer (optional)
Number of messages to pull in a single request. Default is 1.

Administrative

GET /topics

Returns a list of all active topics in the cluster.

GET /topics/{topic_name}/partitions

Inspects the partition assignments, metadata, and current leader distribution for a given topic.
